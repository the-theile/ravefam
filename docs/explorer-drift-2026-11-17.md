# Lineup Explorer drift report — 2026-11-17

Before the Explorer switches to being generated from Supabase, each of the
38 festival pages was compared with its `artist_festival_appearances` rows.
Method: a fingerprint per festival, then per artist, of
`artist | day | stage | start | end | headliner`, page vs DB
(`_ops/explorer/fingerprint.mjs`, SQL in the session log).

**25 festivals match exactly. 13 drift**, and the drift goes both ways.

## What drifted

| Festival | When | Page vs Supabase |
|---|---|---|
| BOO Arizona | Oct 30 (past) | DB has 5 of 31 acts; 26 missing. Days missing; 5 headliner flags missing |
| Cyclops Cove 4 | **Dec 4** | DB has 29 of 56 rows; 27 acts missing. Days missing on all 29 |
| Dreamstate SoCal | **Nov 20** | Days missing on all 70 (stages and times match) |
| DUSK Arizona | Nov 13 (past) | Days missing; Soaplab missing; Fetty Wap, Horsegiirl, Phantogram not flagged headliners |
| EDC Orlando | Nov 6 (past) | Days missing; **3 names differ** (below); 4 page cards lack set times the DB has (Obskür, Nico Moreno, Luke Dean b2b George Smeddles); festival `days` is empty |
| Ember Shores | **Nov 20** | Days missing; ILLENIUM's 3 solo sets aren't in the DB (only the b2b with Subtronics is) |
| Hulaween | Oct 21 (past) | Days missing; The String Cheese Incident's 2 later sets not in the DB |
| III Points | Oct 16 (past) | Days missing; **page is behind**: DB has stages and set times for ~50 acts the page doesn't show |
| Lights All Night | **Dec 30** | Days (dec30/dec31) missing on all 40 |
| Lost In Dreams LA | Jul 11 (past) | JVNA's K-Pop set: DB stage Lucid, page Vivid (the DB row's own note says Vivid) |
| Lost Lands | Sep 18 (past) | Krewella missing |
| Metamorphosis | Aug 28 (past) | Canabliss missing |
| Seven Stars | Oct 9 (past) | 7 acts with more than one set (GRiZ, LSDREAM, Sippy, …): only the first set is in the DB |

Biggest pattern: set-time migrations filled stage and time but never `night`,
so the app's day grouping falls back to times. B2B sets were stored as a
"b2b set" note, never as a linked `b2b_group`.

## The fix: one reconcile, adds only

`supabase/migrations/20261117030000_explorer_reconcile.sql`
(generated by `_ops/explorer/reconcile.mjs`, **not applied yet**):

- fills `night`, `b2b_group`, and any missing stage or set time on existing rows;
- headliner = page OR DB;
- inserts the page cards the DB lacks (missing acts, extra sets);
- never overwrites a DB value and never removes a row;
- switches the lineup-alert triggers off for the transaction, so fans don't get
  "just added" pings for acts that were already public on the Explorer.

Tested on BOO Arizona, Ember Shores and Lost In Dreams inside a transaction that
was forced to roll back: correct rows, 0 alerts queued, triggers back on.

After it runs, the generator (`_ops/explorer/build-explorer.mjs`) brings the pages up to
the DB: III Points and the 4 EDC cards get their set times. Everything else is
already identical: a generator run against a snapshot of today's pages changes 0 of 38 pages.
