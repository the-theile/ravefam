# EDC Orlando 2026 × RaveFAM: set times campaign

Three carousels for the week before EDC Orlando (Nov 6–8, Tinker Field). Post 1 announces the set times, post 2 shows clash control and the crew layer, post 3 covers festival mode and the RaveFAM app. Each one sends people to the free Lineup Explorer (no signup).

- **Format:** 4:5 feed carousels, 1080×1350 PNG. 9 images, 3 per post.
- **Suggested time:** 6–7 PM ET.
- **Data:** set times are the real ones from `get_lineup_set_times` (Oct 30). The crewmates (Sam, Kai, Jess, Theo) and the "Lionhearts" crew are demo data. Artist names are text only, with no photos or logos.
- **Link in bio:** `https://myravefam.com/lineup-explorer/edc-orlando-2026`
- **Rebuild:** copy `_build/capture.spec.js` into `tests/` and run it with `--project=chromium`, then run `node marketing/edc-orlando-2026/_build/slides.mjs`.
