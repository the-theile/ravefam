Add Rave: the chosen flow (A + link paste)

One sheet, openAddRaveSheet(ctx), replaces both openRaveEditor() for new raves and openNewRavePopup(). It searches the catalog first, has a one-screen create form, fills that form from a pasted link, requires a map pin for the place, and includes RSVP and crew picking. The wizard stays, but only for editing a rave.

What it replaces

  • openNewRavePopup / saveNewRavePopup and the #new-rave-popup-overlay markup: removed.
  • openRaveEditor() with no id: now opens the sheet. With an id: the wizard, unchanged.
  • saveRave's "new rave" branch becomes a shared createRave(data, ctx) used by the sheet.

Data rules

  • Saving is blocked without a name, a date, and lat/lng or a venue_id.
  • Link autofill also writes ticket_url / official_url (columns already exist).
  • Optional DB guard later: a check constraint for new rows only (not valid), so old rows aren't affected.

Open questions

  • Link autofill: what can link-preview pull from RA, Dice and Instagram pages? Needs a spike before committing to it.
  • Should "Tell a crew?" pre-select a crew? (e.g. the crew page you opened the sheet from.)
  • Version bump: MINOR (new feature).
