Add Rave: one search-first sheet

Replaces both openRaveEditor() (Raves tab "+ Add Rave") and openNewRavePopup() (Profile → Manage raves). Every entry point opens the same sheet, searches the catalog first, and only creates a new rave when nothing matches. The 4-step wizard stays, but only for editing.

Three ways to lay it out. All three include paste-a-link autofill, inline RSVP and choosing which crew to tell. Example query: "awakenings".

Required on every new rave (fixes inconsistent data): NameStart datePlace with coordinates (venue or map lookup) DaysTicket / official linkColour (auto)
A

Search sheet that expands into a form

A bottom sheet with one field: "Rave name or paste a link". Matches appear as you type. Tapping "Create" opens the form in the same sheet with the name already filled. Takes the fewest taps, and works the same from the Raves tab and from a profile.

B

Link first, with a ticket preview

Same sheet, but the main action is pasting a link. The link fills in a gig-poster style ticket (reusing the Rave Share Card look) as a live preview. Fields that came from the link are cyan, and anything missing is amber. The duplicate check runs on the filled-in name, date and coordinates.
